# Git worktrees in one Herdr workspace

Open a project shell in its Herdr workspace, then `prefix+f` to open its Neovim editor. Inside Neovim, `<leader>gw` (`:WorkspaceWorktrees`) lists Git worktrees by branch/path and opens the chosen checkout's **editor tab in the same workspace**. `<leader>gW` (`:WorkspaceWorktreeShell`) opens a branch-labelled **shell tab** for starting an agent; an editor pane cannot host `herdr agent start`. The existing `prefix+f` shortcut remains scoped to the invoking shell's checkout.

`workspace-editor --checkout <listed-worktree-path> [--shell]` is the launcher behind the picker. It rejects paths that are not live worktrees of the invoking repository. Before changing focus or creating a tab, it runs `direnv exec` if the selected checkout has `.envrc`. Clipforge specifically refuses branches missing `.envrc` or the expected local dev/renderer ports; review the file and run `direnv allow <checkout>` per worktree. A rejected selection displays a Neovim error and does not open a tab. Old Clipforge branches predating the local-env pilot need their own reviewed update before selection.

New Herdr panes use **Fish**; the interactive Fish direnv hook loads approved checkout env before the shell prompt, so `herdr agent start <name> --kind pi --pane <shell-pane>` inherits the checkout's env and cwd. This was smoke-tested via a read-only inspection of the launched Pi process environment, without printing secrets. An already-running agent/editor keeps its launch-time environment: create a new checkout tab to use another worktree or restart a stale process. Changing only Neovim's cwd cannot change an existing agent. Never put staging/deploy credentials in automatically loaded local files; a checkout selection is not cloud authorization.

The launcher focuses the selected checkout when invoked deliberately. It does **not** move existing panes or create another workspace. Avoid deleting worktrees with open tabs or private `.local-dev` evidence. Existing legacy worktrees are left where they are; layout migration is separate from navigation.
